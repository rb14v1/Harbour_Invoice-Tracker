# Accepted dependency risks

Policy (`sec.no_critical_cves`): no dependency may ship with a CRITICAL or
HIGH severity CVE. Upgrade to a patched version whenever one exists. If no
fix is available, add an entry below. Each entry needs a justification, any
mitigations and a review date. When the review date passes, check the entry
again. Remove it once a patched version is adopted.

Regression prevention:
- `.github/dependabot.yml` opens weekly update and security PRs for pip
  (`/backend`), npm (`/frontend`) and Docker base images (`/backend`,
  `/frontend`).
- Before release, run Trivy locally to scan for vulnerabilities:
  `trivy fs --scanners vuln --severity CRITICAL,HIGH --exit-code 1 backend/`
  and
  `trivy fs --scanners vuln --severity CRITICAL,HIGH --exit-code 1 frontend/package-lock.json`.
